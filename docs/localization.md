# V.E.R.A. UI Copy Guide

The active desktop client is in `desktop/src/`. Keep its user-facing copy in
Russian, with V.E.R.A. written exactly with periods and capitals.

| Product term | Russian UI term |
| --- | --- |
| Process | Процесс |
| Processes | Процессы |
| Block rule | Правило блокировки |
| Network Radar | Network Radar |
| Startup | Автозапуск |
| Settings | Настройки |
| Verified | Проверен |
| Blocked | Блокируется |

Avoid using the former product name in new copy. Technical identifiers, such
as `VERA_DATA_DIR`, API action names, and Windows registry keys, remain in
English.
